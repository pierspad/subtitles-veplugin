# Subtitles 1.2.0

- Keep up to 200 recent subtitle downloads between sessions, including language metadata and matching video choices.
- Choose whether a successful download opens Downloads or keeps Search open for more downloads.
- Remove a download from history, with an explicit option to delete its SRT file. Associated videos are always kept.
- Open downloaded subtitles in Flashcards or Synchronize. Compatible Vesta builds show amber and cyan workflow buttons and can open the saved file's folder.
- Keep subtitle language metadata independent of subsequent searches and filename markers.

Flashcards and Synchronize handoffs, file-folder actions, and workflow button colors require a Vesta build with the corresponding plugin support. Older hosts keep their default button styling. This plugin release does not publish or update Vesta itself.
